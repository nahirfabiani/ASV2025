# Estructura de Carpetas del Informe

## Carpetas creadas:

### /planos
- Coloque aquí los archivos de planos técnicos (DWG, PDF, etc.)
- Formatos recomendados: PDF, DWG, JPG, PNG

### /imagenes  
- Coloque aquí las fotografías del relevamiento
- Formatos recomendados: JPG, PNG, WEBP
- Organice por ubicación o tipo de problema

### /documentos
- Coloque aquí los documentos complementarios

### /pdf
- Coloque aquí el informe técnico completo en formato PDF
- Archivo principal: informe-auditoria-seguridad-vial.pdf

## Funcionalidad implementada:
- Botón "Descargar PDF" en la sección Anexos
- Modales para visualizar planos e imágenes
- Estructura preparada para contenido real
